# Phase 13.6.2 — Dashboard navigation

Dashboard KPI and system pulse cards now open their related ERP section:
- sales KPIs / customers / sales invoices / receipts -> Sales
- inventory value -> Inventory
- suppliers / purchases -> Purchases
- production KPIs / production orders -> Production
- items -> Master Data (Items)
- employees -> Employees
- maintenance -> Maintenance
- risks -> Risk Control
- approvals -> Governance

The version pulse card is informational and shows 0.13.6.2.
