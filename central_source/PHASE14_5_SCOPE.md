# Phase 14.5 — تخطيط الإنتاج والمواد والمخزون

- تجميع خطط الطلب المعتمدة للشهر والمنتج عبر جميع المحافظات.
- احتساب مخزون المنتج النهائي القابل للاستخدام في مخزن FG.
- سياسة مخزون لكل صنف: أيام مخزون الأمان + زمن التوريد، بدون افتراض أرقام مسبقة (القيمة الافتراضية صفر).
- صافي احتياج الإنتاج = الطلب المعتمد + مخزون الأمان - المخزون المتاح.
- تقريب الإنتاج إلى عدد صحيح من الطرحات وفق الوصفة النشطة.
- احتياجات المواد حسب BOM وعدد الطرحات ونسبة الفاقد المتوقعة.
- مخزون الأمان ونقطة إعادة الطلب والشراء المقترح لكل مادة.
- المخزون المتاح للمواد يعتمد على الرصيد القابل للاستخدام في مخزن RM بعد استبعاد المنتهي والمحجور/الموقوف وخصم الكميات المحجوزة لأوامر إنتاج مفتوحة.
- إنشاء خطة إنتاج مسودة ثم اعتمادها، والخطة المعتمدة لا يعاد حسابها إلا بعد إعادة فتح موثقة.
- جميع تغييرات السياسات والتوليد والاعتماد وإعادة الفتح تدخل سجل التدقيق.
- Room schema: 16 -> 17.
