Implemented
- Existing treasury rows are grouped using stable groupCode, backfilled from the existing treasury code.
- A logical treasury can contain multiple currency-specific posting accounts.
- Each currency keeps a separate GL account and separate original-currency balance.
- Treasury edit screen: name, type, bank metadata, active state. Stable code is preserved.
- Add Currency action creates a dedicated ASSET posting account atomically under the same logical treasury.
- Add Currency requires TREASURY_POST + ACCOUNTING_POST; editing requires TREASURY_POST.
- Customer collection still requires an exact treasury currency match and now explains how to add a missing currency.
- Cloud treasury mirror carries group_code.
- Supabase group_code migration and backward-compatibility trigger were applied to the connected FUSH-ERP project.
- Audit actions: TREASURY_UPDATE and TREASURY_ADD_CURRENCY.
