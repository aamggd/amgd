# Phase 14.5.46 — Tax / VAT Accounting Framework

## الهدف
إضافة إطار ضريبي محاسبي قابل للتهيئة دون افتراض نسبة قانونية أو تفعيل ضريبة تلقائيًا، مع حفظ لقطة الضريبة على كل فاتورة وربط ضريبة المخرجات/المدخلات بالأستاذ وسجل ضريبي تفصيلي.

## النطاق
- Schema 37 (BRANCH ONLY / PROVISIONAL) عبر Migration 36 -> 37.
- Tax Codes قابلة للتهيئة: `SALES`, `PURCHASE`, `BOTH` مع نسبة صريحة من المستخدم.
- لا توجد نسبة ضريبة افتراضية ولا تطبيق تلقائي؛ `taxCode = null` يعني بدون ضريبة.
- الفاتورة والمرتجع يحفظان snapshot: رمز الضريبة، النسبة، الوعاء، مبلغ الضريبة بالعملة الأصلية والأساسية.
- حساب رقابة `1400 — ضريبة مدخلات قابلة للاسترداد`.
- حساب رقابة `2410 — ضريبة مخرجات مستحقة`.
- ضريبة المبيعات: ذمة/نقد إجمالي شامل الضريبة، الإيراد قبل الضريبة، وضريبة المخرجات التزام مستقل.
- ضريبة المشتريات القابلة للاسترداد: مخزون قبل الضريبة + أصل ضريبي + المورد/النقد بالإجمالي.
- ضريبة المشتريات غير القابلة للاسترداد: تُرسمل داخل تكلفة المخزون ولا تُسجل كأصل ضريبي.
- المرتجعات تعكس نفس نسبة الضريبة التاريخية المخزنة في الفاتورة، لا النسبة الحالية للرمز.
- عمولة المندوب تُحسب على المبلغ قبل الضريبة فقط.
- سجل `tax_ledger_entries` للمخرجات والمدخلات والمرتجعات.
- مطابقة نهاية الفترة: الأستاذ لحسابي VAT يجب أن يساوي سجل الضريبة قبل السماح بالإقفال.
- منع القيود اليدوية المباشرة على حسابي VAT باعتبارهما حسابي رقابة.
- شاشة «الضرائب» لإدارة الرموز وعرض تقرير المخرجات والمدخلات وصافي الضريبة.
- لا destructive migration.

## مبدأ قانوني
هذا إطار محاسبي تقني فقط. النظام لا يفترض أن المنشأة مسجلة ضريبيًا ولا يفترض نسبة 5% أو 15% أو غيرها؛ النسبة والنطاق يتمان بإعداد صريح من الإدارة وفق المتطلبات القانونية الفعلية.
