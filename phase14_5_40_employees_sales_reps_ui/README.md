# FUSH ERP Mobile — Phase 14.5.40 Employees & Sales Representatives UI

Apply after Phase 14.5.39 in numeric order (`01` through `08`).

This phase adds professional employee/HR and sales-representative presentation: KPIs, search/status filters, employee production-compensation visibility, training/authorization validity, sales/collections/returns metrics, commission lifecycle, and clearer linked vouchers.

It preserves account 2200 employee-labor accrual/payment behavior, account 2300 sales-commission behavior, commission earning/reversal rules, employee production compensation calculations, Room schema, DAOs, posting and reversal services.
