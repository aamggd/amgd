# FUSH ERP Mobile — UI Professionalization 5: Inventory & Master Data

Baseline: `0.15.4.37-ui-accounting-treasury`
Target: `0.15.4.38-ui-inventory-master-data`

## Scope
Presentation and usability improvements for inventory, warehouses, items, units and unit conversions.

## Implemented
- Inventory workspace KPIs for stocked item locations, reorder alerts, expiry alerts and active warehouses.
- Clear quick actions for count, transfer, opening stock, legacy lot assignment and master data.
- Searchable warehouse/category stock balances with sellable, expired and controlled quantities.
- Risk-aware reorder/expiry alerts and professional count, transfer, lot and movement cards.
- Professional master-data workspace with counts, section hierarchy, search and item/unit/warehouse/conversion status presentation.

## Safety boundary
No stock quantity, lot allocation, inventory costing, count posting, transfer posting, opening-stock posting, reorder calculations, master-data validation or database schema are intentionally changed.
